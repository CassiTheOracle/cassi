# Balance–Spiral Observability Gate — Pre-registration

## Status: Plan—pre-registered 2026-08-17, before any live run

This document freezes the read-only calibration protocol for the balance-built Qi-spiral program. The run measures whether the live CassiCosmos mind engine exposes stable balance and organized phase-current proxies before any objective is trained or any steering arm is implemented. An honest null closes the corresponding mechanism for this field representation.

## 1. Authority and scope

The field authority is `scripts/cassi_mind_engine.gd`, driven through the line-delimited JSON bridge on `127.0.0.1:7599`. The pinned scene is `scenes/mind_engine_cache.tscn`: `grid_n = 32`, `auto_step = false`. After the frozen initial-condition deposits, the probe performs no deposit or field mutation other than explicit `step` commands.

The bridge payload named `q_b64` is

$$P = E_Y^2 + E_I^2,$$

and is called **field power** here. It is not the canonical coherence diagnostic. The probe computes

$$\rho = E_Y + E_I,$$
$$\varepsilon = E_Y - \varphi E_I,$$
$$q_{\mathrm{coh}} = \frac{\rho^2}{\rho^2 + \varphi^{-2} + \varepsilon^2},$$
$$\theta = \operatorname{atan2}(E_I,E_Y).$$

The engine arrays are density-like state variables, not verified amplitude fields. Therefore

$$\mathbf{J}_{\mathrm{proxy}} = E_Y\nabla E_I - E_I\nabla E_Y$$

is a **phase-current proxy**, not the canonical amplitude-field current $\mathbf{J}=\Psi_0\nabla\Psi_1-\Psi_1\nabla\Psi_0$.

## 2. Frozen initial conditions and schedule

- Grid: $N=32$; all four decoded arrays must have exactly $N^3=32768$ little-endian float32 values.
- Seed: `20260817`.
- Initial condition: 10 deposits generated by the existing `field_steer.py` family: positions uniform in $[-0.8,0.8]^3$; sigma selected from `{0.5, 1.0, 1.5, 2.0}`; one third at `cy = φ ci`; two thirds independently uniform `cy,ci ∈ [-1,1]`.
- The IC is flushed by one engine step, producing readout $r=0$.
- Eight measurement intervals use the frozen cadence

$$\tau_r=\max(1,\operatorname{round}(\varphi^{r-1})),\qquad r=1,\ldots,8,$$

which is `[1, 2, 3, 4, 7, 11, 18, 29]` under Python rounding for these values.
- A full readout is taken after each interval. No steering deposit is made.

## 3. Infrastructure gates

All gates must pass at every readout.

- **O1 protocol:** `ping`, `clear`, every IC deposit, every `step`, and every `readout` reply has `ok=true`.
- **O2 shape:** `ey`, `ei`, payload `field_power`, and payload `eps2` have equal size $N^3$.
- **O3 finite:** every decoded value and every derived metric is finite.
- **O4 payload identities:** payload field power agrees with $E_Y^2+E_I^2$ and payload epsilon squared agrees with $(E_Y-\varphi E_I)^2$ to maximum absolute tolerance $10^{-5}$. This is an encoding identity gate, not a physical threshold.
- **O5 deterministic controls:** repeated construction of each control from the same seed produces byte-identical arrays.

Failure of O1–O5 is `INVALID`, not a physical verdict.

## 4. Frozen observables

For every readout, report full-distribution summaries rather than means alone:

1. **Balance:** mean, standard deviation, RMS, and percentiles `{1,5,25,50,75,95,99}` of $\varepsilon$ and $|\varepsilon|$; the same summaries for $q_{\mathrm{coh}}$ and field power.
2. **Density-conditioned balance:** 16 equal-population bins in $\rho$ where possible; within each bin report median $\varepsilon$ and median absolute deviation. This is calibration output for a possible manifold $\varepsilon_*(\rho)$, not a fitted confirmation target.
3. **Temporal phase continuity:** principal phase increment

$$\Delta\theta = \operatorname{angle}\left(e^{i(\theta_r-\theta_{r-1})}\right)$$

weighted by $w=\sqrt{P_rP_{r-1}}$; report circular resultant and weighted mean absolute increment.
4. **Phase-current proxy:** periodic central differences on each axis with unit grid spacing; report RMS and percentiles of $|J_x|,|J_y|,|J_z|$, plus axial fraction

$$f_z=\frac{\langle J_z^2\rangle}{\langle J_x^2+J_y^2+J_z^2\rangle}.$$

5. **Helical order scan:** for each axis and integer mode $m\in[-8,8]$, compute

$$H_{a,m}=\left|\frac{\sum_x P(x)e^{i[\theta(x)-2\pi m x_a/N]}}{\sum_x P(x)}\right|.$$

Record the maximum $H_*$, its axis and mode. Mode zero is reported separately; a nonzero-mode mechanism claim requires a nonzero winning mode.
6. **Persistence:** report the time series and endpoint/baseline ratios for $\varepsilon_{\mathrm{RMS}}$, $q_{\mathrm{coh}}$ mean, $J_{\mathrm{proxy,RMS}}$, and $H_*$.

## 5. Matched controls

Controls are recomputed at every readout from the same $E_Y,E_I$ arrays and fixed control seed `20260818`.

- **Spatial shuffle:** one common random permutation is applied to both $E_Y$ and $E_I$. This preserves the pointwise pairs and exact distributions/power but destroys spatial organization.
- **Fourier phase scramble:** for each component, preserve the 3D real-FFT amplitude spectrum and replace phases with phases from a deterministic real Gaussian field, then inverse-transform. Rescale each reconstructed component to the original mean and standard deviation. This preserves the spectral envelope and component moments but not pointwise Yang–Yin pairing.

The same observable code runs on the live field and both controls. No separate metric implementation is allowed.

## 6. Calibration statistics

This run does not adopt an objective. It produces calibration distributions and the following contrasts:

- $\Delta H_{\mathrm{shuffle}}=H_*^{\mathrm{live}}-H_*^{\mathrm{shuffle}}$;
- $\Delta H_{\mathrm{phase}}=H_*^{\mathrm{live}}-H_*^{\mathrm{phase}}$;
- corresponding contrasts for $J_{\mathrm{proxy,RMS}}$ and temporal phase resultant;
- balance-manifold stability: Spearman correlation of per-bin median $\varepsilon$ between the first and final readouts, reported only when at least 8 bins contain data;
- persistence ratios for all live observables.

No effect-size threshold is invented here. The output is used to freeze tolerances and thresholds in a separate confirmatory pre-registration.

## 7. Decision tree

Applied top to bottom:

1. O1–O5 failure → **INVALID**.
2. All live and control phase/current metrics are numerically zero → **NO OBSERVABLE PHASE CURRENT**.
3. A nonzero-mode live $H_*$ never exceeds both matched controls at any readout, or the winning mode is unstable across all eight readouts → **NO EVIDENCE OF ORGANIZED SPIRAL**.
4. Live $H_*$ or $J_{\mathrm{proxy}}$ is matched or exceeded by both randomized controls throughout → **NOISE-COMPATIBLE / MECHANISM NOT SUPPORTED**.
5. Live nonzero-mode order exceeds both controls and persists, while balance and field power remain finite and non-collapsed → **OBSERVABLE—ELIGIBLE FOR CONFIRMATION**. This is eligibility only, not adoption.
6. If live-control separation changes sign or the best mode is horizon-dependent → **INCONCLUSIVE—CALIBRATION UNSTABLE**.

The balance manifold is never declared from this single seed. It is reported as `CANONICAL-LINE`, `DENSITY-CONDITIONED CANDIDATE`, or `UNRESOLVED` descriptively; confirmation requires a multi-seed protocol.

## 8. Stopping rule

The run completes all eight intervals. It stops early only for O1–O4 failure, non-finite data, engine disconnection, or an explicit process failure. No adverse trend, weak signal, or apparent null permits early stopping or metric changes.
