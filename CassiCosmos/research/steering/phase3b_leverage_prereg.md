# Phase 3b — Steering Leverage: Pre-registration

## Status: Plan — pre-registered (2026-08-15), before any Phase-3b run

This document fixes the statistic, decision tree, and stopping rule for the
Phase-3b leverage follow-up **before any Phase-3b run executes**. It inherits
the Wave-2 verdict-grade machinery and ledger discipline from
`phase3_steering_prereg.md` (whose tree D0–D5 and increment-framed statistic
serve as the base), and extends it to the four leverage arms and the
long-horizon G34 check below. No claim below is a measurement.

## 0. Inherited context (measured in Wave 2, not re-argued)

The Wave-2 verdict grade on `field_steer.py` (deterministic engine,
`auto_step=false`, `grid_n=32`, fresh solver per arm, ledgered):

- Control `--strength 0`: `G0 = -0.5905` (target coherence decays naturally).
- Cadence-yang `S` (per-unit leverage): 0.1 → 0.895 (**NULL/D3**); 0.25 → 1.073;
  0.5 → 1.112; 1.0 → 1.148 (**SUPPORT/D2** at ≥ 0.25, monotone in strength).
- Per-step reference (bounded 20-rung window): `S = 1.437` (**SUPPORT/D2** within
  its window), with the explicit caveat that the window does not span G34's
  full-horizon degradation.
- All arms: `pi_sat = 0`, all rungs alive, no NaN, no boundaries.
- Peak cadence-yang leverage ≈ 1.15. **This is the baseline to beat.**

The question this pre-registration answers: **can per-unit leverage S be raised
above ~1.15, and does per-step injection degrade over G34's long horizon?**

## 1. Statistic (same increment framing as Wave 2)

Identical to `phase3_steering_prereg.md` §2: over a window of `R` cadence rungs
(`r = 1..R`, baseline `r = 0`), target region `A` = Chebyshev ball of radius
`r_A` around the target cell `T` (default `r_A = 1`, 27 cells), compute

```
Q_A(r) = Σ_{i∈A} q_i(r),   q_i = ey_i² + ei_i²
ΔQ_steered(r) = Q_A(r) − Q_A(r−1)
Δdeposit(r)   = Σ deposits in rung r (|cy| + |ci|)
G_cad  = Σ ΔQ_steered(r)          (steering arm's build)
G_0    = Σ ΔQ_0(r)                (control build, no injection)
σ_ΔQ   = std(ΔQ_steered(r))       (margin)
S      = Σ ΔQ_steered / (Σ Δdeposit + ε_charge),   ε_charge = 1e-9
```

The **primary verdict statistic** is `S` (total per-unit leverage), judged
against both the Wave-2 baseline `S_base` and the do-nothing floor
(`G_cad > G_0 + 2σ_ΔQ`).

**Leverage-improvement test** (the new question): an experimental arm "improves
leverage" iff `S_exp > max(S_base, 1.0) + margin_L`, where `S_base` is the
Wave-2 cadence-yang reference at the same strength (0.25 → 1.073) and
`margin_L = 0.05` (a pre-stated, non-negligible improvement — 5 percentage
points, above run-to-run noise seen in Wave 2). If no arm crosses this, the
result is **flat** (valid deliverable).

## 2. Aliveness constraint (identical to Wave 2)

A window is valid only if for every readout: **A1** all `ey/ei/q/eps2` finite
(NaN-loud-fail, HARD STOP); **A2** `q_mean(r) ≥ q_floor · q_mean(0)`
(`q_floor = 0.05`); **A3** `π_sat_frac(r) ≤ π_sat_max`
(`π_sat_frac = (1/N³)·#{q_i ≥ q_sat}`, `q_sat = 100.0`, `π_sat_max = 1e-6`).

## 3. Stopping rule (fixed before any run)

- NaN (A1) ⇒ HARD STOP, arm INVALID, boundary recorded.
- A2/A3 fail on 2 consecutive rungs ⇒ arm INVALID, boundary recorded.
- A run needs ≥ 6 valid rungs for any verdict (matching Wave 2); the
  long-horizon arms need their full `R` (well above 6).
- Fixed `R = --rungs` and `N_max = --steps` budget; no adaptive stopping on `S`
  (no peeking, no early-out on the leverage metric).
- Fresh solver per arm: `clear` + IC, never shares state.

## 4. Pre-registered arms (fresh solver each, ledgered into THIS file)

Arm numbering continues the Wave-2 ladder. All cadence arms use
`--mode yang --cadence phi` unless noted. IC = the Wave-2 seed IC
(`--seed 20260815 --ic-deposits 10`).

- **7 — finer injection (arm a):** lower per-rung charge with more rungs.
  `--lam-max 0.15 --rungs 24 --strength 0.5` (vs the Wave-2 `lam_max = 1.0`,
  `rungs = 8`). Hypothesis: smaller, more frequent φ-ratio injections ride the
  attractor with less inter-rung diffusion, raising `S`.
- **8 — annular placement (arm b):** `--placement annular --strength 0.5
  --rungs 8`. The per-rung charge is split evenly across the 26-cell Chebyshev
  shell at radius 1 (the TSC stencil footprint) around the target, each cell a
  φ-ratio deposit, preserving total charge. Hypothesis: distributed placement
  buys more target coherence per injected unit than a single-cell scatter.
- **9 — target refinement (arm c):** `--target-x <fixed> --target-y
  <fixed> --target-z <fixed> --strength 0.5 --rungs 8`, targeting the SAME
  attractor cell the projection would return (explicit coords), compared to
  `--target` absent (project k=8, read-side top cell). Hypothesis: the
  read-side choice (explicit vs project-read) does not change leverage when
  both resolve to the same attractor — a reference-plane/consistency check.
- **10 — 64³ resolution confirm (arm d):** if a 64³ `auto_step=false` scene is
  available (new `scenes/mind_engine_64.tscn` created, not an edit of an
  existing scene), rerun cadence-yang at `--strength 0.25 --rungs 8` on the
  64³ engine (auto_step=false). Compare `S` to the 32³ Wave-2 value (1.073).
  If the 64³ scene cannot be launched, record a documented limitation and do
  NOT substitute an auto-step run as a verdict.
- **11 — long-horizon G34 check (arm e):** `--per-step --strength 0.25
  --rungs 200 --steps 500`, extending the Wave-2 per-step reference well beyond
  its 20-rung window to span G34's degradation horizon. Primary read: the
  trajectory of `Q_A` (target coherence) — does it collapse ~10× relative to
  control, or persist? If per-step degrades long-horizon, that confirms G34 and
  strengthens cadence discipline; if it persists, that is a finding too
  (bounded window was representative).

## 5. Decision tree (D0–D5 inherited, plus the leverage-improvement test)

- **D0** connection/infrastructure (ping/clear/IC + charge-exact ≤ 1e-3 rel err).
  Fail ⇒ arm INVALID (infra), recorded.
- **D1** aliveness abort (A1 NaN ⇒ HARD STOP; A2/A3 2-consecutive ⇒ INVALID).
- **D2 (per-arm SUPPORT, as Wave 2):** `G_cad > G_0 + 2σ_ΔQ` AND `S > 1.0`.
- **D3 per-arm NULL:** `G_cad ≤ G_0 + 2σ_ΔQ` OR `S ≤ 1.0`.
- **D4 REGRESSION:** target attractor collapses ~10× relative to control
  (`Q_A(end) ≤ ε_A ≈ 0` while control healthy), OR (for arm e) per-step
  long-horizon reproduces the ~10× degradation.
- **D5 alive-but-not-steering:** aliveness OK but `S ≤ 0`.
- **Leverage-improvement test (applies to arms 7–10):** if
  `S_exp > max(S_base, 1.0) + 0.05` with `S_base = 1.073` (the 0.25 cadence
  reference), the arm **improves leverage**. If no arm does, the Phase-3b
  conclusion is **flat** (valid deliverable — leverage plateaus ≤ ~1.15 on
  this operator/cadence).

No post-hoc tuning. A flat or negative result is a valid, recorded deliverable.

- Engine launched windowed (never `--headless` — local RD requirement).
- `auto_step = false` scene for all verdict arms (grid_n=32 or 64); engine only

- No edits to the 30-arm verify battery, any existing scene, or any shader.

  `scenes/mind_engine_64.tscn` (grid_n=64, auto_step=false, bridge_port=7599).
- No CassiAI code is imported or used.
