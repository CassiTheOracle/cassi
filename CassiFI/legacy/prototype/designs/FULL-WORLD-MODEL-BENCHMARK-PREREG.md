# Full field-native world-model benchmark preregistration

## Status: FROZEN BEFORE RUN—2026-08-22

## Purpose

Measure predictive performance of the complete `cassi_world_model.py` implementation
rather than the specialized L28 system-identification arm. The benchmark evaluates
one fixed model configuration on two deterministic trajectory families:

1. **Native family**: trajectories generated by the same fixed Cassi modal operator
   used by the model, with an action-driven field state and partial observations.
2. **Off-family transfer**: trajectories generated by a nonlinear damped four-state
   dynamical system that does not use the Cassi modal recurrence.

The result is a model-quality and transfer smoke benchmark. It is not a claim about
language, raw-image/audio multimodality, Qwen intervention value, or live engine
authority.

## Frozen metrics

For each family, record:

- teacher-forced observation MSE;
- teacher-forced reward MSE;
- continuation accuracy;
- open-loop observation MSE after a `16`-step observed prefix;
- open-loop reward MSE after the same prefix;
- persistence-baseline open-loop observation MSE;
- training and validation total loss at first and final epochs;
- wall-clock training time;
- evaluation throughput in steps/second;
- peak device memory when available;
- finite outputs and checkpoint round-trip equality.

The persistence baseline predicts each future observation as the final observation
from the observed prefix and predicts reward/continuation with their training-set
means. It is a comparator, not a learned control.

## Decision tree

1. **FAIL** if any required artifact is absent, any tensor/metric is non-finite,
   checkpoint round-trip changes deterministic predictions, the train/test episode
   IDs overlap, or the recorded configuration/digests differ from this document.
2. For each family, mark **SUPPORTS** if the full model beats persistence by at least
   `5%` on open-loop observation MSE and has finite teacher-forced and open-loop
   metrics.
3. Mark **NULL** for a family when mechanical checks pass but the 5% transfer
   threshold is not reached.
4. The overall result is:
   - **SUPPORTS** if native and off-family both SUPPORTS;
   - **EMERGES** if native SUPPORTS and off-family is NULL;
   - **DOES NOT EMERGE** if native is NULL with mechanical checks passing;
   - **FAIL** if any mechanical gate fails.
