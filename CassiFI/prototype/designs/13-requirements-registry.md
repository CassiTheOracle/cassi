# CassiFI requirements registry

This file is an index, not a competing definition. The owner documents remain
normative for equations, schemas, package contracts, gates, and failure
semantics. Each stable `QI-*` requirement appears exactly once in the table
below. G15B recomputes the rows, follows every owner-document link, verifies
the named work package and gate, and rejects a missing, duplicate, extra, or
orphaned entry. The single hashed
`cassi.qi-flow-dependency-manifest.v1` is authoritative for the W/G/prose/
Mermaid/registry graph; this table is checked against its owner/consumer edges.
