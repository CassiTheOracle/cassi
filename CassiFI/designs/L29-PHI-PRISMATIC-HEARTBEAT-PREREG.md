# L29 Phi-Prismatic Heartbeat Field — Frozen Preregistration

## Status: FROZEN — 2026-08-30

This protocol is frozen before the L29 executable field, runner, verifier, or canonical artifacts are created. The canonical run is one deterministic CUDA/ROCm float32 board. Engineering smoke tests may use small CPU/float64 states, but their results cannot alter this protocol.

## Question

Does one heartbeat-powered seven-bank field with logarithmically uniform phi timescales improve coherent multihorizon retention over resource-matched four-bank and nongeometric seven-bank controls without allowing input events to supply field energy?

A positive result applies only to the frozen layout `cassi.qi-prismatic-shared-coordinate.v1` and operator `cassi.qi-prismatic-heartbeat.v1`. It does not establish phi as a universal field constant and does not change the live four-bank CassiFI runtime or its checkpoints.

## Frozen field

The sole adaptive state is one `QiFieldState.field` tensor with shape `[S, 9*M, B]`. Only modes `[0, M/2)` are active; modes `[M/2, M)` remain exactly zero. The nine planes retain the live order:

`Y_re, Y_im, I_re, I_im, VY_re, VY_im, VI_re, VI_im, epsilon2_ema`.

Every bank uses one shared immutable boundary codebook generated by:

```python
QiFieldController(
    QiFieldConfig(
        scale_count=1,
        mode_count=M,
        alphabet_size=260,
        primes=(4093,),
        settle_steps=1,
    )
).codebook(0)
```

The prismatic operator does not call the live sensing, evolution, correction, consolidation, checkpoint, or diagnostics paths.

### Common and differential coordinates

For complex Yang/Yin position and velocity:

\[
D=Y-\phi I,\qquad C=\phi Y+I,
\]

\[
Y=\frac{D+\phi C}{1+\phi^2},\qquad
I=\frac{C-\phi D}{1+\phi^2},
\]

with \(\phi=(1+\sqrt5)/2\). The same transform applies to velocities.

### Heartbeat

One heartbeat occurs at the start of every logical tick, including ticks with no input. Seven-bank arms inject only at bank 3 (`heart`). The four-bank control splits the same aggregate target equally across banks 1 and 2.

The heartbeat measures active dynamic energy

\[
E=\operatorname{mean}\!\left(\sum_{p=0}^{7}F_p^2\right)
\]

across the source bank or weighted source pair. If \(E<1\), it radially rescales all eight active dynamic planes to `heartbeat_target_energy = 1.0`; if \(E\ge1\), it injects nothing. A zero source is initialized with uniform unit common position \(C\), zero differential position \(D\), and zero velocities, then rescaled. The heartbeat never changes `epsilon2_ema`.

### Zero-net-energy input

For codebook unit phase \(u=e^{i\theta_x}\), `source_trust` \(g\in[0,1]\), and \(\alpha=\pi g/2\), root input applies the unitary transform

\[
D'=\cos\alpha\,D+\sin\alpha\,uC,
\]

\[
C'=\cos\alpha\,C-\sin\alpha\,\bar uD,
\]

and the identical transform to common/differential velocities. It changes information-bearing phase and the allocation between common and differential modes while preserving total dynamic magnitude. Input applied to an all-zero state remains zero.

### Bank dynamics

For active mode \(m\), bank \(k\), and timescale \(\tau_k\):

\[
p_m=1+0.25\frac{m}{\max(W-1,1)},\quad W=M/2,
\]

\[
\omega^2_{km}=\frac{p_m}{\tau_k^2},\qquad
\gamma_k=\frac{0.2}{\tau_k},\qquad
g_k=\frac{0.002}{\tau_k^2}.
\]

With `dt = 0.05` and \(R^2=|C|^2+|D|^2\), both common and differential modes use

\[
V\leftarrow e^{-\gamma_k dt}V+dt\left[-\omega^2_{km}X-g_kR^2X+F_{\rm coupling}\right],
\]

\[
X\leftarrow X+dt\,V.
\]

`epsilon2_ema` moves toward \((|Y|^2-\phi|I|^2)^2\) with

\[
\alpha_{\epsilon,k}=1-(1-0.05)^{1/\tau_k}.
\]

Each active dynamic scalar is bounded to `[-8, 8]`; active mean dynamic energy is bounded to 32 by uniform rescaling; `epsilon2_ema` is bounded to `[0, 8**4]`. Every component clamp or aggregate rescale is counted. Any canonical clamp fails mechanics.

### Reciprocal bank coupling

For adjacent banks \((k,k+1)\),

\[
\kappa_{k,k+1}=\frac{0.25}{\tau_k\tau_{k+1}}.
\]

For both \(C\) and \(D\), add \(\kappa(X_{k+1}-X_k)\) to bank \(k\) and its negative to bank \(k+1\). Endpoints have no flux.

Diagnostic Hamiltonian is

\[
H=\left\langle\frac{
\tfrac12(|V_C|^2+|V_D|^2)
+\tfrac12\omega^2(|C|^2+|D|^2)
+\tfrac14g(|C|^2+|D|^2)^2
}{1+\phi^2}\right\rangle
+\sum_{\rm edges}\left\langle\frac{
\tfrac12\kappa(|\Delta C|^2+|\Delta D|^2)
}{1+\phi^2}\right\rangle.
\]

### Crown/white readout

Each bank's active differential field is projected into the shared 260-symbol complex codebook. Divide each coefficient vector by that bank's differential RMS, discard banks with energy below `1e-8`, and sum the remaining complex coefficients without candidate-specific phase alignment. Symbol score is `abs(sum)**2`. Readout is available only when crown energy is at least `1e-8` and at least two banks are active.

For each candidate,

\[
C_{\rm white}=\frac{|\sum_k a_k|^2}{N_{\rm active}\sum_k|a_k|^2+10^{-12}}.
\]

Exact score ties are resolved by smaller symbol ID.

## Frozen arms

All arms share `dt`, physics coefficients, coupling law, heartbeat target, alphabet, fastest and slowest timescales, normalized within-bank modal bandwidth, logical ticks, and evolution steps.

| Arm | Banks | Mode count | Timescales |
|---|---:|---:|---|
| `phi-7` | 7 | 3512 | \(\tau_k=\phi^k,\ k=0..6\) |
| `linear-time-7` | 7 | 3512 | \(1+k(\phi^6-1)/6\) |
| `linear-frequency-7` | 7 | 3512 | \(1/[1-k(1-\phi^{-6})/6]\) |
| `geometric-4` | 4 | 6146 | \((1,\phi^2,\phi^4,\phi^6)\) |

Every arm has exactly:

- `S * 9 * M = 221256` scalar state values per batch;
- `S * 8 * (M/2) = 98336` active dynamic values per batch;
- 16 evolution steps per logical tick.

The board records edge updates, element updates, peak allocated bytes, and wall time because equal state does not imply equal edge cost.

## Frozen board

The canonical device is CUDA/ROCm float32. Inputs and schedules are deterministic; there are no learned parameters or random seeds.

### Mechanical probes

For every arm:

1. Apply symbol 0 with trust 1 to an all-zero clone; store pre/post fields.
2. Apply the first heartbeat to another all-zero clone; store pre/post common/differential fields, velocities, and receipt.
3. Warm a fresh state for 128 input-free ticks, each `heartbeat -> evolve(16)`.
4. From that warmed state, continue 128 input-free ticks for the beating trace.

Record per-bank active dynamic energy, Hamiltonian, injected heartbeat energy, clamp count, maximum heartbeat-only `abs(D)`, and top three non-DC FFT bins. Using NumPy linear quantiles:

\[
B=\frac{p_{99}(H)-p_{01}(H)}{\operatorname{median}(H)}.
\]

### Retention probe

Clone each warmed state to batch size 8. Frozen targets are

`(0, 37, 74, 111, 148, 185, 222, 259)`.

At tick 0 apply those targets with trust 1. At tick 8 apply distractors `(target + 97) % 260`. Every tick executes `heartbeat -> optional input -> evolve(16)`. Read after ticks

`(0, 1, 2, 4, 8, 16, 32, 64)`.

Retain all 260 white/per-bank scores, target and distractor ranks, white coherence, active energy, Hamiltonian, heartbeat injection, input-energy drift, and raw common/differential fields.

Primary statistic: mean reciprocal rank of the original target over all eight examples at ticks `(16, 32, 64)`.

Immediate statistic: distractor accuracy at tick 8.

Best-bank statistic: the highest single-bank original-target MRR over the same examples and long-horizon ticks.

### Mechanical FAIL

Return `FAIL` before scientific classification on any of:

- missing/non-sibling artifact, noncanonical JSON, nonfinite value, hash/schema/profile/source/config mismatch, wrong arm set, malformed raw shape, or reported/recomputed metric mismatch;
- unequal scalar-state, active-dynamic, endpoint-bandwidth, damping-law, logical-tick, or element-update budgets;
- first-heartbeat source-energy relative error above `1e-5`;
- heartbeat-only maximum `abs(D)` above `1e-6`;
- maximum instantaneous input dynamic-energy drift above `5e-5`;
- input produces a nonzero all-zero state;
- any dynamic/epsilon clamp or nonfinite state;
- final warmup root or crown active energy below `1e-4` of total active dynamic energy;
- any arm beating index above `1.0`.

### Scientific verdict

With mechanics green, return `SUPPORTS` only if every condition holds:

1. `phi-7` tick-8 distractor accuracy is at least `0.75`.
2. `phi-7` long-horizon white MRR is at least `1.05 * geometric-4`.
3. `phi-7` long-horizon white MRR is at least `1.02` times each nongeometric seven-bank arm.
4. `phi-7` long-horizon white MRR is at least `1.02` times its best single-bank MRR.

Return `CONTRADICTS` if any condition holds:

1. `phi-7` long-horizon white MRR is at most `0.95` times `geometric-4` or the better nongeometric seven-bank control.
2. `phi-7` white MRR is at most `0.95` times its best single-bank MRR.
3. `phi-7` beating index exceeds `1.25` times both nongeometric seven-bank beating indices.

Otherwise return `NULL`.

The report begins with the eight targets, distractors, tick-8 white predictions, target reciprocal ranks at ticks 16/32/64, per-arm beating indices, and white-versus-best-bank MRR. Hashes and artifact inventory follow behavior.
